Selected Work

Full list on Google Scholar

  1. 01 Preprint · 2025 AFRO

    Bootstrap Dynamic-Aware 3D Visual Representation for Scalable Robot Learning

    Qiwei Liang, Boyang Cai, Minghao Lai, Sitong Zhuang, Tao Lin, Yan Qin, Yixuan Ye, Jiaming Liang, Renjing Xu

    Self-supervised pre-training that learns dynamics-aware 3D visual representations from action-free data, through latent inverse dynamics and feature diffusion, so that robot policies scale with unlabeled demonstrations.

    Paper Project Code

  2. 02 AAAI 2026 DQ-Bench · DQ-Net

    Whole-Body Coordination for Dynamic Object Grasping with Legged Manipulators

    Qiwei Liang, Boyang Cai, Rongyi He, Hui Li, Tao Teng, Haihan Duan, Changxin Huang, Runhao Zeng

    DQ-Bench, a benchmark for grasping moving objects with a quadruped manipulator, and DQ-Net, a teacher–student policy that coordinates legs and arm to grasp objects in motion.

    Paper Project Code

  3. 03 Preprint · 2026 RoboNVS

    Beyond Viewpoint Generalization: What Multi-View Demonstrations Offer and How to Synthesize Them for Robot Manipulation?

    Boyang Cai*, Qiwei Liang*, Jiawei Li*, Shihang Weng*, Zhaoxin Zhang*, Tao Lin, Xiangyu Chen, Wenjie Zhang, Jiaqi Mao, Weisheng Xu, Bin Yang, Jiaming Liang, Junhao Cai, Renjing Xu

    A controlled study of what multi-view demonstrations give a policy beyond viewpoint robustness, and RoboNVS, a geometry-aware framework that synthesizes novel-view videos from a single monocular demonstration.

    Paper Project Code

  4. 04 Preprint · 2026 AEM

    Action-Effect Memory Pretraining for Robot Manipulation

    Yijing Zhou, Qiwei Liang, Sitong Zhuang, Jiaxi Li, Xianpeng Wang, Boyang Cai, Yunyang Mo, Renjing Xu

    Masked modeling over interleaved vision–action histories compresses what past actions did to the scene into a single memory token, giving visuomotor policies history awareness at almost no inference cost.

    Paper Project
